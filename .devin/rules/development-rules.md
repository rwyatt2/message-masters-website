# Message Masters Development Rules

## Core Principles

### The Distinctness Standard
Could a direct competitor sign this? If yes, it fails. Every component, section, and interaction must be unique to Message Masters.

### The Verification Standard
Can we show where this came from? Every claim, statistic, and statement must be traceable to the brand manifesto or verification section.

### The Order Standard
Purpose > Identity > Strategy > Expression. Never backwards. The website must follow this order in presenting information.

## Design Rules

### Color Usage
- Signal Blue (#2B7CB1) is an accent - use sparingly, not everywhere
- Deep Void (#0B0D10) for dark backgrounds and sections
- White (#FFFFFF) for main content areas
- Black (#14181C) for primary text
- Graphite (#252729) for secondary dark elements

### Typography Rules
- Use Poppins font family only
- Headlines: ALL CAPS, -68 tracking, 0.84 leading
- Body text: Sentence case, normal tracking, 1.66 leading
- Never use Visby CF (retired from brand system)
- Use bold greater-than sign (>) for sequence arrows (Poppins has no arrow character)

### Logo and Mark Rules
- Always use the seven-sided mark (never 6 or 8 sides)
- Never regularize side count at small sizes
- Never snap to grid for layout convenience
- Keep wavy edge - it's part of the mark
- Below 24px, use wordmark alone
- "Built on Purpose" lockup line sits under wordmark, small caps, letterspaced

### Layout Rules
- Full-bleed dark dividers between sections
- Card grids for services and content
- Tinted belief boxes for key statements
- Running footer on all pages
- Dark field aesthetic with single accent

## Content Rules

### Writing Style
- Reading level: Grade 8
- No em dashes (use full sentences, commas, colons, periods)
- No jargon: synergy, leverage, ecosystem, elevate, unlock, transform, journey, solutions
- No urgency/scarcity tactics
- Full sentences, clear and direct

### Forbidden Words
- Generic (say "a document anyone could have signed" instead)
- Branding (means logos to our buyer, implies cost)
- Full-service marketing agency (we are not one)
- Cohesive communications system (describes process, not outcome)
- Business therapy (client's word, not ours)
- Any marketing jargon or buzzwords

### Required Words
- Build, Own, Purpose, Value, Message, Master, Share
- Written down, Excavate, Verify, Order, Discover
- Clarity, Working order, The room, Honest, Worth it

### Naming Conventions
- Strong single nouns
- INSIGHT (capitalized)
- The Manifesto, The MasterPlan, The MasterPlan Lite, The Manager, Media (initial capital + definite article)
- The Plain Page, The Brand File, The Wordsmith step, The Room, The Declaration, Verification

## Technical Rules

### Code Quality
- Clean, readable code
- Proper comments where needed
- Follow React best practices
- Use functional components with hooks
- Proper error handling

### Performance
- Lazy load sections and components
- Optimize images and assets
- Minimize bundle size
- Use code splitting where appropriate
- Implement proper caching strategies

### Accessibility
- WCAG AA compliance
- Proper color contrast ratios
- Keyboard navigation support
- Screen reader friendly
- Semantic HTML structure
- Alt text for all images
- Proper heading hierarchy

### SEO
- Proper meta tags
- Semantic HTML
- Fast loading times
- Mobile responsive
- Proper heading structure (H1, H2, H3, etc.)
- Alt text for images

## Testing Requirements

### Mandatory Tests
- Cross-browser testing (Chrome, Firefox, Safari, Edge)
- Mobile testing (iOS, Android)
- Tablet testing
- Desktop testing (various screen sizes)
- Accessibility testing (screen readers, keyboard navigation)
- Performance testing (Lighthouse scores)
- Color contrast verification

### Brand Verification
- All colors match brand guidelines exactly
- Typography settings are correct (tracking, leading, weights)
- Logo usage follows all rules
- Messaging matches brand manifesto
- No competitor could sign this website

## Development Workflow

### Before Starting
- Read the relevant section of the brand manifesto
- Understand the purpose of the component/section
- Verify any claims or statistics
- Check that it follows the order (Purpose > Identity > Strategy > Expression)

### During Development
- Reference brand manifesto for all decisions
- Use brand colors exactly as specified
- Follow typography rules precisely
- Write content at grade 8 level
- Ensure accessibility

### Before Committing
- Verify distinctness (competitor test)
- Verify claims (source test)
- Check typography settings
- Test on multiple devices
- Run accessibility checks
- Verify color contrast

## Anti-Patterns

### What to Avoid
- Generic components that could work for any company
- Copying competitor designs
- Deviating from brand colors
- Using forbidden words
- Skipping the order (Purpose > Identity > Strategy > Expression)
- Making claims without verification
- Using urgency or scarcity tactics
- Overusing the accent color
- Simplifying the logo mark

### What to Do Instead
- Create unique, brand-specific designs
- Reference brand manifesto for all decisions
- Use exact brand colors
- Write clear, direct content
- Follow the order strictly
- Verify all claims
- Use honest, straightforward messaging
- Use accent color sparingly
- Keep logo mark as designed (7 sides)

## Success Criteria

A successful Message Masters website:
1. Could not be signed by a competitor
2. Every claim is verifiable
3. Follows Purpose > Identity > Strategy > Expression order
4. Uses exact brand colors and typography
5. Is accessible to all users
6. Performs well on all devices
7. Loads quickly
8. Ranks well in search engines
9. Converts visitors to INSIGHT evaluations
10. Accurately represents the brand
